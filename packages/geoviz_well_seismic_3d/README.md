# geoviz_well_seismic_3d

Well–seismic joint 3D analysis scene for Paleo Workbench / geo-viz-engine.

Provides `WellSeismicScene` (survey, vertical domain, well geometry, injectable
volume access) and `WellSeismicJointWidget` (facade over `geoviz_seismic.Renderer3D`).

See parent PRD #57 and ticket #58.
